# Shared cup collection

## Current source scene

The active collection now uses the multi-object desk photograph and visible-mug annotations documented in [TABLETOP_SOURCE.md](TABLETOP_SOURCE.md). The coffee source and its annotation below describe the previous revision, retained for historical evidence. They are not the active playground input. The runtime fingerprint changes with this source revision, so earlier experiments must be rerun while their written answers are preserved.

coffee.png is the scikit-image coffee photograph, courtesy of Pikolo Espresso Bar.
The photographer is Rachel Michetti. The source identifies this image as CC0 with no copyright restrictions.

Source documentation: https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.coffee
Maintainer extraction: scripts/prepare_assets.py using scikit-image 0.26.0.

All methods use the exact same 31 images generated by the shared dataset module. The untransformed photograph is the tuning reference. Evaluation contains 20 controlled variants (including two target-absent distractors), 9 transformed synthetic target-absent controls and 2 independent photographs, with unique image IDs and labels.

Normal uses translated crops. Dim changes all pixels. Glare adds a highlight. Far shrinks apparent size without asserting physical distance. Occluded covers part of the scene. Rotated rotates the same scene. Cluttered adds competing bright regions. Distractor contains bright shapes without a cup. Each variant changes one primary factor.

Blur uses fixed Gaussian kernels. Background replaces pixels outside the manually annotated cup silhouette with a constructed patterned scene. It is a controlled composite, not another physical camera view. The independent photographs vary real background, design and viewpoint together.

`tabletop_annotation.json` records the active manually traced visible-mug polygon and handle hole, independently of model predictions. Geometric transforms align reference masks with the image, and occlusion removes covered pixels. Negative masks are empty. The two independent photos have no pixel annotations. Mask IoU/Dice scores exclude those photos and state the both-empty convention explicitly. Active source boxes describe visible extent because the mug is clipped at the top of the photograph.

## Independent photographs

- `independent_mug.jpg`: Coffee in a mug, Kurt Kaiser, CC0 1.0. Source and license: https://commons.wikimedia.org/wiki/File:Coffee_in_a_mug.jpg
- `independent_cup.jpg`: Coffeecup, Sprinno, CC0 1.0. Source and license: https://commons.wikimedia.org/wiki/File:Coffeecup.jpg

Downloaded originals are bundled. Runtime letterboxing preserves proportions. These images include a different viewpoint and a travel-cup shape. They deliberately change several variables and are not paired causal tests. They are excluded from the tuning playground. Once inspected, they are no longer an unseen holdout. Students should describe any subsequent tuning accordingly.

Reference rectangles were manually estimated from the bundled images on October 19, 2026. They enclose the cup and handle, excluding the saucer. Controlled variants transform the reference rectangle with the image. Occlusion uses the full inferred cup extent. Rotation uses an axis-aligned enclosing rectangle. Box metrics use IoU >= 0.50, with extra unmatched predictions counted as false positives. The small, approximate annotation set is a teaching aid, not a benchmark or demographic fairness evaluation.
